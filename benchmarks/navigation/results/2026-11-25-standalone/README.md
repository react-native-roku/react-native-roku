# Standalone suite verification on the Roku Ultra

The ordinary React and full-title Solid fixtures each completed 30 moves with zero failed inputs or missing trace tails on the Ultra 4850X. Each fixture had one fresh launch. This run verified the benchmark pipeline. Measuring a latency advantage requires repeated launches in both orders.

| Physical workload      | Observed behavior                                                                                                                                                                                                                                                       |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Public starter catalog | All 20 steps completed in both unmarked and marked launches. Detail opened Card 16. Back restored Card 16 at 600 px. Seven mounted-window updates had scoreable post-apply swaps in each trace.                                                                         |
| Second input           | Continued Down, Up reversal and paced Down each reached the intended Detail and restored focus and scroll. A separate marked launch verified the expected activation sequence. The first marked attempt reported Perfetto ordering errors and was excluded from timing. |
| Nine directions        | The retained renderer settled on Card 48. Card 64 was required. The executable gate failed and retained the trace and replay.                                                                                                                                           |
| Image-backed holdout   | The unpaced run stayed on Route 7 when Route 8 was required. The same ZIP passed all 16 settled checks on the separately paced trace.                                                                                                                                   |
| Gallery                | The packaged image loaded, a missing resource reported failure, the image unmounted, and the packaged image loaded again.                                                                                                                                               |
| Settings               | The modal opened twice. Dismissing it with Back and then with Select restored focus to the edit control both times. Physical text entry and spoken output need separate checks.                                                                                         |

The source checkout installed from the public registry. A second clone installed offline from that independently populated store. The host checks covered 629 renderer tests, 110 build tests, both TypeScript configurations, the package manifest, 14 registered modules and 131 API entries. The pack-only catalog host benchmark exercised 12, 72 and 240 cards. The navigation suite also ran its Python and Node regressions without hardware.
